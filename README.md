# CordCracking

CordCracking est un outil web permettant de créer des formations de blocs Minecraft en 3D, 
d’attribuer une valeur de rotation à chaque bloc et 
de rechercher automatiquement les coordonnées correspondant à cette formation.

L’application est utilisable en local ou disponible directement ici :

https://cordcracking.onrender.com

## Projet original

La logique de recherche est basée sur le projet de 19MisterX98, sa version est beaucoup plus rapide bien que plus compliquée à utiliser :

https://github.com/19MisterX98/TextureRotations

Pour utiliser correctement le système, les resource packs nécessaires doivent être récupérés depuis ce dépôt original, 
notamment dans la section des releases. Ces packs permettent d’associer les rotations des textures aux valeurs utilisées par le programme.
